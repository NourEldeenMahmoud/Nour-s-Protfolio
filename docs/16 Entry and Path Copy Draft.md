## Publication Safety Rules for All Copy

1. **No unverified claims.** The copy states what the path organizes and presents; it does not claim employment status, seniority, production scale, team size, metrics, or hiring availability.
2. **No invented facts.** All project references in path copy are drawn from the five flagship projects confirmed in `02 Content and Case Studies.md`.
3. **Role language is honest.** "Role fit" means the content helps a recruiter evaluate fit; it does not assert fit.
4. **Watch is not video-only.** Copy explicitly uses "directed media" and "project worlds," not "video."
5. **General is the default.** Copy for the skip/continue action clearly says "general portfolio," not "error" or "fallback."
6. **English and Arabic are equivalent.** Both languages receive the same factual scope and the same calls to action.
