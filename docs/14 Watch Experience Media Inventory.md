# Watch Experience Media Inventory

## Overview

Watch is a media-forward cinematic route for visitors who came to see Nour's work (D-042). It is **not** a passive video-only page. Watch uses directed screenshots, interactions, workflows, project identities, and signature moments as its primary navigation system while retaining evidence labels and ownership context.

**Arabic title (العنوان بالعربية):** جرد وسائط تجربة "مشاهدة"

## Watch Path EN/AR Parity Requirements

Every media asset used in Watch must satisfy:

1. **Alt text** in both English and Arabic.
2. **Captions** for any video with speech or essential audio, in both languages.
3. **Descriptive text** for diagrams and workflow visualizations, in both languages.
4. **Context labels** (project name, role, context badge) in both languages.
5. **Evidence labels** displayed identically in both language versions.

No media asset may appear in one language version without its equivalent in the other.

## Provenance and Accessibility Concerns

| Concern               | Rule                                                                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Asset provenance      | Every media asset must have a documented source (repository capture, original recording, generated diagram). No unattributed assets.              |
| Copyright             | Only assets created by Nour, licensed for use, or captured from Nour's own projects may be used. Third-party assets require license verification. |
| Alt text quality      | Alt text must describe the visual content meaningfully, not just repeat the file name.                                                            |
| Video captions        | Any video containing speech must have captions. Any video with essential audio must have a text alternative.                                      |
| Diagram accessibility | Diagrams must include a text-based explanation or long description.                                                                               |
| Lazy loading          | Media below the fold must be lazy-loaded.                                                                                                         |
| Poster images         | Video must use poster images.                                                                                                                     |
| No autoplay audio     | Watch must never autoplay audio.                                                                                                                  |
| Mobile reduction      | Heavy media must reduce to lighter static versions on mobile.                                                                                     |
| File format           | Prefer AVIF/WebP for images; compressed MP4/WebM for video.                                                                                       |
