## Evaluation Criteria

Score each prototype from 1-5:

- Communicates .NET depth.
- Makes broad range feel intentional.
- Avoids common portfolio templates and AI-generated visual tropes.
- Supports Recruiter, Client, and Developer worlds.
- Supports English and Arabic equally.
- Produces a memorable first 30 seconds.
- Keeps project evidence readable.
- Has a complete mobile reduction.
- Can meet an acceptable performance budget.
- Can be maintained as projects and tutorials grow.

## Prototype Deliverable

For Project Multiverse and Cinematic Product Stories, prototype only:

1. Shared entry and audience selector.
2. One selected-work transition.
3. The first screen of Bookify.
4. English-to-Arabic switch.
5. Mobile reduction.

Do not build the complete portfolio to decide the art direction.
